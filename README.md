# atelier · 立绘馆

A129 独立仓库网页：养成立绘图鉴、表情对白与场景工坊。四位主线角色，半身 / 全身姿势可切换，棋盘格透明底，可叠到不同背景上。

## 线上地址

- 首页：https://dannyling111.github.io/a129-atelier/
- 仓库：https://github.com/dannyling111/a129-atelier

纯静态页，打开即可。数据在浏览器本地。

## 里面有什么

- 图鉴：陆南风、沈清和、周远白、顾修朗
- 角色页：站姿 / 侧身 / 半身表情
- 工坊：抠图叠到场景
- 养成：好感与对白

## 本地

```sh
npm install
npm run dev
```

GitHub Pages 构建：

```sh
npm run build:pages
```

`dist/` 就是发布目录。
